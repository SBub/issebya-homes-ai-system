# Branding Guidelines

## Brand Name

The official brand name is **issebya.homes** (lowercase, with a dot).

**Correct usage:**

- `issebya.homes`

**Incorrect usage:**

- ~~Issebya Homes~~
- ~~ISSEBYA HOMES~~
- ~~issebya homes~~
- ~~Issebya.Homes~~

## Usage in Code

### Page Titles

Use the brand name in page metadata titles:

```typescript
export const metadata: Metadata = {
  title: "Page Name - issebya.homes",
};
```

### Examples from Codebase

- `src/app/layout.tsx` - Root layout with site name
- `src/app/ui/Header.tsx` - Header with brand display
- `src/app/ui/Footer.tsx` - Footer with copyright
